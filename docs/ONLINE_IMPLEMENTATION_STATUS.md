新 C 诊断按冻结的 52 个开发来源比赛评估，平均仿真评分差 +0.292，单侧 95% 下界 +0.048；独立回放 104,416 次行动，0 非法/未完成。记录见 `experiments/g-c-expansion-20261022/dev-summary.json` 与 `dev-audit.json`。

这只通过“允许继续训练低成本候选提议器”的诊断门槛，不是实战胜率结论。随后已用 78 个训练局面完成固定提议器：开发集平均评分差 +0.218，但单侧 95% 下界 −0.026，未过门槛；额外提议耗时 P95 1.95ms。盲测结果未打开、正式 AI 不替换；详见 `docs/AI_PROPOSER_PROGRESS_20261022.md`。
