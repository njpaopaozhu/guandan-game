# 玩家界面与后台取消修复验收

本轮交付简化单机与好友房界面，修复关闭仔细思考或结算时未及时释放后台任务的问题。默认快速策略、正式v17、规则引擎及已发布Worker出牌逻辑保持原基线，不发布未通过对照的候选开关改动。

## 玩家体验

- 首页直接开局，牌桌明确标识自己、队友和左右对手；训练统计、牌谱导出与本机AI连接收进设置中的高级选项。
- 操作以出牌、不出、提示为主。无效或压不过上一手的选择不能提交；设置输入框中的Enter、S和Esc不触发背后牌桌动作。
- 手牌可用空格选择，弹窗打开时移入键盘焦点，关闭时回到入口。遵循减少动画偏好。
- 手机按实际可用宽度缩放手牌，不裁掉边缘牌；提示与操作区不重叠。好友房开局前只显示约局与准备流程，区分我方、队友与对方。
- 单机入口会检查同源好友房服务。邀请与二维码在本机服务中完成，隐私授权默认关闭；不自动启动服务或开放公网。

## 验收

- `npm test`：206项核心测试通过，另通过后台取消、当前回合快速回退、结算丢弃旧动作与硬截止检查。
- `npm run test:online`：22项通过。当前默认服务器策略的一场完整比赛实际过A，13副、1,359次行动、11次贡还操作独立重放，零非法。该测试不代表新AI强度认证。
- 真实Chrome在1280、768、390、320像素宽度完成开局、27张手牌边界检查、键盘选牌、设置输入与Esc隔离，以及正常四人轮转，零页面异常。
- 在后台注入3秒延迟的故障场景中，实际点击切回快速和认输结算后，后台均被取消，未收到迟到结果，下一副各座位重新发到27张牌。故障注入仅验证控制流程，不作速度或棋力成绩。
- 两个独立浏览器身份通过好友入口、邀请链接、二维码、对家换座、准备开局和两个电脑席位完成真实轮转；390与320像素无横向溢出，零页面异常，默认数据授权保持关闭。
- 单机与好友房均在从未存在的`dist/guandan-player-ui-20261025-*-r2`目录构建，清单、运行依赖闭合与包内测试通过。此前r1包含未晋级候选，只作为本地实验存档，不作为本次交付包。

本地浏览器证据保存在`output/playwright/player-ui-acceptance-20261025-r5`和`output/playwright/player-ui-online-acceptance-20261025-r2`，不上传截图、会话、邀请令牌或测试存档。

## AI工作结论

Worker候选开关对齐是会改变出牌行为的独立策略变量。598对全新正式对照完成后，候选胜率49.16%，保守配对95%区间约48.08%–50.28%，未达到预登记点估计至少50%的门槛，因此撤回该候选改动。无追加牌序、改门槛或把回归通过当作强度提升，未启动其后续过A晋级验收。
