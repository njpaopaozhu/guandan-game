# 公开信息残局诊断

本轮补齐“全信息上限”和“实际可用信息”之间的验证。正式 AI、v17、Worker 均未改动，以下结果不是整体棋力提升，也没有发布实验策略。

## 方法

在原先固定的110个发现局面中，穷举由自己手牌、已出牌和各座位剩余张数允许的全部物理牌分配。每种分配均重建四家初始27张牌，重放完整公开行动历史，确认它能到达相同的公开局面。过牌只按规则校验，不解释成“手中没有能接的牌”。本批来源都是无贡还的首副牌，适配器明确拒绝未实现的历史或贡还情形。

对每种分配比较所有合法起手选择。后续四个座位各自使用被冻结的快速策略，只允许读取自己的手牌与公开信息。每个起手动作在所有分配中保持一致，没有按暗牌真相挑选不同的起手。记录真实规则结算的升级分和单副输赢，不使用全信息求解器的推荐动作或分值作为续局输入。

独立审计采用另一种分配枚举方法，重新构造所有世界和公开历史，复算后续快速策略，校验行动、结算、汇总以及相同可见信息下的动作一致性。漏世界、重复世界、错误归属、篡改分数、缺行动、替换策略动作、缺起手候选、错汇总8类坏证据均被拒绝；另验证超限拒绝、历史不支持拒绝和真实暗牌读取拦截。

## 结果

- 110个局面、393种合法分配、11,756次行动全部复验。
- 10,444次后续策略决策经过重新计算；8,002种可见信息状态，零暗牌读取。
- 只有3个局面、来自2副发现牌局，存在相对原动作在所有分配中不差、且至少一种分配更好的选择。3个局面不是3个独立样本。
- 这些选择都只减少对方升级，没有改变单副赢家。

原先全信息诊断的三处机会进一步分化：

| 发现案例 | 公开分配验证 | 下一步判断 |
| --- | --- | --- |
| 手牌含一对9和一对2的领牌局面 | 3种分配下，拆出单张2相对原先出对2，1种更好、2种相同；固定快速续局中均只让对方升1级 | 保留为发现案例；效果依赖指定续局策略，不能作全策略保证 |
| 三张6带Q，跟对4时选择过牌 | 6种分配下，过牌1种更好、5种更差，最坏额外让对方多升2级 | 不采用由真相牌局得出的过牌改判 |
| 两张4带3，只有一位其他玩家持牌 | 未现牌归属唯一；先出对4相对先出3，固定续局中让对方少升1级 | 优先研究可由公开信息完全推知余牌的精确残局 |

固定策略下的逐世界不差，不表示对任意对手策略都不差。393种分配的等权平均只作敏感性分析，不是经历史校准的暗牌概率。发现局面已被查看，不能再作为最终盲测或胜率样本。

## 后续范围

优先隔离实现一个很窄但可证明信息来源的能力：只有一个其他座位还持牌、总余牌不超过8张时，从108张牌扣除自己手牌与已出牌，推知其全部余牌，再做有界精确搜索。先验证完整合法候选、真实升级分、超限回退及独立证书；冻结策略后再采新牌序，评估整场升级收益与时间成本。

未知牌仍可能分属多个座位的场景，继续使用固定策略诊断与历史校准研究；不把逐世界最优动作拼接成实战策略。任何新候选仍须独立验收，不能用本报告替代发布门槛。
