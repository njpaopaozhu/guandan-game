# AI 候选提议器执行结果（2026-10-22）

结论：轻量提议器已真实训练并完成开发集独立验收，未通过预登记评分收益门槛。不进入正式游戏、不打开盲测、不根据开发结果调参重跑同一验收。

## 数据与执行

- 原始 234 场数据完整，不再重复启动旧的“153/234 断点续采”。
- 新 C 诊断使用独立来源比赛 130–181 的 52 个公开局面，平均仿真评分差 +0.292，单侧 95% 下界 +0.048，允许推进提议器试验。它并不证明实战胜率提升。
- 在采集训练回放前，封存固定配方：`results/g-c-proposer-plan-20261022.json` 与 `experiments/g-c-proposer-20261022/registration.json`。
- 训练来源比赛 52–129，共 78 个冻结公开局面、547 个候选标签；4 个选动作世界的完整回放评分减去默认动作评分，按来源比赛等权拟合。保留有放回采样产生的重复牌分布，不按结果过滤。
- 训练回放独立复演 149,824 次实际行动；所有 2,812 条训练续局与 1,872 条诊断开发续局的完整公开根状态再次核对；无非法动作、未完成续局或对手暗牌读取。
- 39 维特征、96 棵固定小树，保留默认动作并提议至多两个替代动作，最后仍执行正式回放的剪枝与改判门槛。没有修改正式 AI、v17 权重或页面默认行为。
