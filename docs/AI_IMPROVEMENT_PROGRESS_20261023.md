# 掼蛋 AI 新一轮执行记录（2026-10-23）

本轮目标是先修复自主续局模型的新牌局泛化，再验证完整回放加速，最后进行同预算实战验收。规则回归、数值一致和模仿准确率都不等于棋力提升。正式 AI、v17 权重及好友房运行代码暂未替换。

## 已完成：冻结基线与新数据

- 基线提交：`cb45077a868e24b73c6e741bc1a6628d700143e1`。
- 原核心 204 项、出牌顺序 286 项、单张清理 17 项、双强牌收尾 21 项、百搭同型收尾、联机 22 项回归通过。保留大牌控权、对手报单封堵和不破坏更短组合路线等正确反例，不机械要求出最小牌。
- 新采集器修复已完成阶段重复创建工作线程、调度异常清理和恢复保护；活跃进程禁止重启，死锁须明确恢复并保留旧锁，未登记的孤立数据片与缺失标签不能被跳过或覆盖。
- 先验收 13 副、覆盖 13 级的小批次，再继续其余 897 副；总计 910 副全新 G 原生 v1/legacy 自对弈。四个座位均使用真实续局规则教师，不用旧根策略轨迹替代。
- 保留全部 93,877 个实际决策、837,002 个候选，其中领牌 15,518、跟牌 78,359，唯一候选局面 37,043。教师动作覆盖 100%，没有插入目标动作或删除未命中样本。
- 全部 93,877 次行动、初始发牌、终局、公开传输包、教师动作和候选由独立环境重建；零非法、零未完成、零暗牌读取、零牌桌状态变更。
- 360,747,862 项 Float32 输入由独立 NumPy 实现逐位重建，零差异。按完整物理发牌指纹排除旧训练、旧开发及新采集内部重复，即使换座也不能混入。
- 原始数据 3,170,577,914 字节。数据、私有存档、检查点及凭据继续留在本地，不上传现有公开 GitHub 仓库；这份文档不是完整数据备份。

## 已固定：两种模型与新的开发集

- A：431 维输入，64/32 隐层；B：增加 16 项廉价余牌结构、自身实物牌顺序特征，447 维输入，同样 64/32 隐层。没有递归规划或教师评分作为新特征。
- 两者都固定 32 轮、128 局面批次、同一学习率和正则化；只取最终轮，不按开发集挑检查点，不追加第三种配方。批次与上一轮 64 局面不同，不能把成绩差异完全归因于数据规模。
- 两种表示共用相同训练牌局和标签，原始目标不变。结构表示中“目标与其他候选输入完全相同”的训练局面从 1,821 降到 1；这不是准确率提升证据。
- 首批新增结构特征的 190,288 项数值独立 JS/NumPy 逐位一致。新增恢复、审计反篡改、运行时边界检查共 16 项通过。
- 真实 RTX5060/CUDA 前向已验证；两种最终模型均封存后，才另生成 78 副、每级 6 副的开发集。开发牌局不能与本轮 910 副或旧开发牌局混合。

## 未完成及停止门槛

目前尚未完成两种模型的训练、全新开发质量验收与独立导出/检查点审计。多候选一致率须 ≥65%，领牌 ≥50%，跟牌 ≥65%，开发 CE 相对未训练模型下降 ≥20%；唯一候选不能抬高主指标。

质量通过之后还须检查学生策略自身轨迹的误差累积、相同工作量完整回放成本及实际 700ms 预算表现。完整回放加速目标 ≥1.2 倍，不能把候选/编码片段计时当作端到端速度。质量或速度不达标，不接入正式 AI；按计划另行登记截断价值叶备选路线，预言机终局分填回只验证接线，不证明模型可学。

只有上述门槛通过，才进行 104 对同发牌换座筛查和按功效估算固定样本量的正式评测，另包含完整升 A 比赛。当前未启动新模型强度赛，未证明整体棋力提升；未部署公网，未引入 FableDan 代码、模型或数据。
