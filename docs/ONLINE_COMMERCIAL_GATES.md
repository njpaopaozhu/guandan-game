# 商业化推进与上线门槛

## 本轮已授权的边界

好友私房内测与AI隔离实验；不代购服务器、不开放防火墙、不创建公网隧道、不配置真实支付。

## 产品阶段

1. **私房可用**：邀请、2–4真人、AI补位、完整升A、断线重连；保留离线版。
2. **受控线上内测**：确认服务器、域名、HTTPS和预算后，完成实际跨网络、长时间稳定性、备份恢复与容量分档测试，再邀请首批真实体验者。
3. **账号与好友**：明确运营主体与身份方案后，再接账号注册、找回、身份迁移、好友关系和好友邀请通知。暂不触达用户通讯录或第三方社交账号。
4. **付费验证**：先看真实开局/完赛/次日回访与服务成本，再验证高级复盘、专项训练、外观及私人房间管理的需求。付费不得提供其他座位暗牌或联机对局特权。

## 收费前必须完成

- 目标地区、运营主体、服务条款、隐私和未成年人保护的专项审核；此文档不代替审查。
- 支付渠道、订单状态机、签名验签、重放防护、退款与对账；不能以客户端“支付成功”发放权益。
- 权益授权、过期撤销、重复通知去重、异常订单和客服处理。
- 账号注销、数据导出/删除、保留期限、加密备份、访问审计和安全事件处理。
- 真实并发、跨网络重连、服务重启、数据恢复演练和监控告警。
- 若推广AI实力，必须有冻结对手、同发牌换座与独立审计证据，不使用开发集胜率冒充上线强度。

## 尚需用户确定的信息

部署目标或现有服务器、月预算、域名、开放地区、首批内测规模；收费阶段再确定运营主体与支付方式。未得到这些信息前，本机内测仍可继续，不能声称已完成公网商业上线。
