# 掼蛋后续开发与玩家体验

本轮依据现有实验和代码复核调整优先级。产品界面以开局、选牌、出牌、队友识别和好友邀请为中心；训练统计、外部模型连接及实验结果留在高级选项或研发文档中。联机保持本机验收边界，不开放公网。

## 开发顺序

1. Worker 候选作用域修正已完成正式验收并停止晋级。104 对筛选为50%；按原公式锁定的598对全新正式牌序已完成独立重放，1,196局、128,749次行动零非法或未完成，配对得分3优、13劣、582平。正式胜率49.16%，保守配对95%区间约48.08%–50.28%，未达到事前点估计不低于50%的门槛。保留原有Worker出牌逻辑，候选及完整证据留在实验目录；不进行该候选后续完整过A验收，不修改门槛或追加牌序救成绩。区间跨50%，也不能称为已证明显著变弱。
2. 当前快速AI的残局机会地图已建立：固定52副、覆盖13级，5,672次真实行动、359个公开局面和2,307个合法候选全部独立重放与枚举复验，零非法或暗牌读取。机会数量不等于错误数量，未据此修改正式策略或训练模型。
3. 极小残局离线全信息求解器已完成首批验证：全部110个总余牌不超过8张的局面均求解，28,711个证书节点经过独立规则核验，预算回退及6类坏证书拒绝测试通过。其中3个来源牌局各有1个全信息下可改善升级分的选择。进一步枚举全部393种公开信息兼容分配、重放11,756次固定快速续局行动后，仅有3个局面（2副来源牌局）存在逐分配不差的改判，均未翻转单副赢家；原全信息建议中的一处过牌在6种分配中有5种更差，不能采用。详见`AI_PUBLIC_ENDGAME_DIAGNOSTIC_20261025.md`。下一步优先研究只有一个其他持牌座位、可从公开信息完全推知余牌的有界精确残局；超限回退，不把固定策略证据写成全策略保证。
4. 可推知余牌的精确残局候选在新104对中改判和升级分收益均为0，停止晋级。公开历史预测在新104副三种规则风格中的预测误差下降约3.35%–3.42%，但真实后台两组各104对筛选分别为47.12%和46.15%，均未达到预登记点估计门槛，停止晋级；区间跨50%，不证明显著变弱。416局及45,029次行动经独立重放，详见`AI_PRO_PROGRESS_20261027.md`。预测误差改善不等于胜率提升，正式AI未接入该实验。
5. 只在有独立收益依据的关键场景研究改判学习，保留基线动作和异常回退。还牌优化另做成本小试；贡牌必须遵循最大可贡牌规则，不把强制选择描述为巨大行动空间。

## 验收边界

每项策略改动预登记后单独评测，训练/发现牌局与最终测试隔离。保持同发牌换座、同预算、原始轨迹和独立规则审计。104对用于筛选，最终样本量事先按配对波动与目标效应确定；没有显著差异不证明路线无效，也不证明强度不退化。

当前固定公式的 Worker 正式门槛是单副胜率点估计不低于50%、保守配对区间下界不低于47%，另有时间与完整过A功能验收。该门槛最多支持指定单副端点内的不劣结论，不能写成稳定提升或职业水平。正式AI/v17与未验收实验隔离，研究数据及检查点不进入公开仓库。

## 本轮界面改动

- 单机首页直接开局，操作区以“出牌、不出、提示”为主；队友与对手使用座位关系称呼。
- 桌面和平板整手两行排列，窄屏动态缩放牌宽；不裁掉第27张牌。操作按钮至少44像素高，可用键盘选牌。
- 设置和历史弹窗管理键盘焦点；编辑设置时不触发牌桌快捷键，Esc关闭可关闭的弹窗时不会在背后过牌。
- 训练统计、牌谱导出和本机AI连接收进高级选项。仔细思考的关闭与结算继续取消后台任务。
- 单机好友入口只检测同源联机服务是否可用，单机包不自动启动服务。好友房区分我方、队友与对方，开局前展示准备流程，隐私选择仍默认关闭。

以上功能须通过浏览器、核心/联机回归和全新发布包验证后才交付；阶段进展不表示整个研发路线已完成。
