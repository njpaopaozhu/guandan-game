# 掼蛋游戏

一个完整的掼蛋游戏实现，包含智能AI对手、完整规则系统和现代化UI界面。

## 🎮 游戏特色

### 完整的游戏规则
- ✅ 4人对战（对角为队友）
- ✅ 两副扑克（108张），每人27张
- ✅ 完整的级牌升级系统（从2打到A）
- ✅ 贡牌/还牌逻辑
- ✅ 接风规则

### 丰富的牌型支持
- 单张、对子、三张
- 三带二
- 顺子（5张连续）
- 木板（固定3对连续对子）
- 钢板（固定2个连续三张）
- 炸弹（4张或更多）
- 同花顺（5张连续同花色）
- 四王火箭
- 红桃级牌（逢人配）通配组合

### 智能AI系统
- 能识别并主动出所有牌型
- 根据场上情况选择最优策略
- 队友配合（通常不压队友；下家仅剩1-2张或自己能直接走完时可接管牌权）
- 整手牌候选评分，减少破对、破三、破炸
- 炸弹使用时机判断
- 残局单张负担评估：优先清理难接手的小单张，保留A、级牌和王的控制权
- 公开信息十世界回放训练的36维候选评分模型（96棵极端随机树）
- 训练模型只在整手牌搜索判定为同档的合法候选间重排，异常时自动回退规则AI

### v2策略增强（2.4.0）
- **记牌推理**：跟踪本局已出/已过的牌，判断某单张是否已是外面最大（封顶），指导跟牌与控场
- **威胁分级**：对手≤2张为紧急（不惜代价拦截）、≤4张为危险区（放宽炸弹性价比）；
  持有多套强牌时先用小炸，对手即将出完时果断火箭镇压
- **领牌防喂**：下家剩1-3张时不再无脑喂小单/小对，改出封顶大牌或长牌型，避免送出牌权
- **送队友**：队友濒临出完且对手距离尚远时，主动喂小牌帮助队友接手
- **弱项复用**：对手本局公开压不了的牌型，领牌时优先继续出同类
- **还牌修正**：还牌对象是对手，改为还最小且不拆自己结构的牌；
  修复旧逻辑在级牌≤10时会把自己的红桃级牌（逢人配）还给对手的重大失误
- 最新独立种子整场A/B评测（v2 vs v1，含贡还牌/升级）：100场胜率62%，0非法出牌；
  单局600局胜率53.17%，因此只能视为中等改善，不能宣称策略已大幅领先

### v3策略增强（2.5.0）
- **队友牌权接管**：不再机械地永远不压队友；自己能直接走完，或下家对手只剩1-2张时可抬高门槛
- **残局小单治理**：剩余牌越少，孤立小单张的代价越高，降低最后留下3、4、5等小牌的概率
- **百搭最终校验**：百搭炸弹存在多种解释时，返回动作前再次按最终牌型校验，杜绝“搜索认为能压、规则实际压不过”
- **实验策略隔离**：中盘普通百搭组合生成器已具备，但因A/B赛胜率下降，仅保留为实验模式，不进入默认AI
- v3 vs v2：单局400局胜率50.75%，完整升A比赛60场胜率50.0%，0非法出牌；
  说明本次修正没有整体回退，但下一阶段仍需更强的多轮搜索和训练数据

### 十世界模型升级（3.1.0）

- **独立整局验收**：对上一部署模型的4批互不重叠牌序共1000对/2000局，胜率51.2%，平均每对升级分+0.088，配对95%区间[+0.011,+0.165]，0非法出牌。

### 结构候选增强（2.7.0）
- **同牌型多实物候选**：同样的顺子、对子、三张、三带二、木板和炸弹，会比较不同花色/副本的取牌方法，不再机械拿每个点数的第一张
- **保护潜在同花顺**：能用等价牌完成当前牌型时，优先留下完整同花顺与关键强牌结构
- **领强牌时机**：非收官阶段主动领炸弹、同花顺或四王会计入牌权机会成本；直接走完或两手内收尾仍会果断使用
- **双种子A/B验收**：对上一版共800局，实验版两组胜率分别51.0%和51.5%，合计约51.25%，0非法动作
- **回归测试**：126项核心测试全部通过，并完成20局自动对局无死循环

### 百搭残局规划实验（未进入默认AI）
- **百搭感知搜索**：实验规划器能识别红桃级牌补顺子、木板、钢板和炸弹的剩余手牌路线
- **单副牌结果**：两组共600局胜率约52.33%，0非法动作
- **整场否决**：完整升A比赛40场仅47.5%，未通过长期收益门槛，因此默认AI继续使用已验证的2.7策略
- **收窄实验**：百搭深度规划仅在8张以内残局启用，等待重新完成单局与整场双重验收

### 单张候选与可控收尾增强（2.8.0）
- **单张实物候选补全**：同一点数有多张牌时会比较具体拿哪一张，避免拿走同花顺中的关键牌而留下等价散牌
- **同花顺结构保护**：完整同花顺不再被残局孤张评估错误地当成五张小单牌
- **收尾损伤去重**：出牌后若剩余手牌已能一手走完，不再重复处罚已经无意义的破对、破三损伤
- **强收尾优先**：同为最后一手时，优先保留炸弹、同花顺或四王，提高重新拿到牌权后的走完概率
- **多层验收**：两组独立单局对战共800局胜率约51.88%；完整升A比赛40场胜率55.0%，0非法动作、0未完成比赛
- **回归测试**：137项核心测试全部通过，并完成20局自动对局无死循环

## 🚀 快速开始

### 运行游戏
直接在浏览器中打开 `index.html` 即可开始游戏。

随后打开游戏，点右上角“♟ 专业AI”，勾选启用并保存即可。服务只监听 `127.0.0.1`；未启动、超时或模型返回异常时，游戏会自动继续使用内置 AI，不会卡住回合。

## 📊 游戏规则详解

### 队伍分配
- **队伍A**：玩家0（你）+ 玩家2
- **队伍B**：玩家1 + 玩家3

### 升级规则
根据一局中队伍的名次决定升级数：
- **双上**（包揽前两名）：升3级
- **头游+对方末游**：升2级
- **头游+队友末游**：升1级

### 级牌系统
- 从2开始，每局根据结果升级
- 级牌在炸弹中最大
- 升到A后必须实际打A级；A级局取得头游且队友不是末游才算过A

### 牌型大小
同牌型比点数，特殊规则：
- 炸弹 > 非炸弹
- 四王 > 6张及以上炸弹 > 同花顺 > 5张炸弹 > 4张炸弹 > 普通牌型
- 同张数炸弹再按点数比较
